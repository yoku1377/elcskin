# TacAI H3.0 版本与问题记录

本文件记录可复现证据、修复边界和版本关联。原始采集 CSV、临时分析文件、旧发布包和可执行文件不进入 Git；用文件名、大小和 SHA-256 保持证据可追溯。

## 记录规则

- 每个问题使用唯一编号 `H3-YYYY-MM-DD-NN`，不复用、不删除；结论变化时追加“复核更新”。
- 区分三种证据：源码/自动测试、历史数据回放、独立硬件验收。前两者不能替代第三种。
- “已修复”只表示已声明范围内的问题不再复现；未覆盖角度、力段、设备或环境必须列入“仍待验证的边界”。
- 版本与 Git 用版本号和同名 tag 关联；tag 指向的提交就是该版本的可追溯源码快照。
