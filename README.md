# elcskin

电子皮肤项目，包含力/触觉传感器数据的监测与可视化工具。

## 目录

- `TfgMonitor/`：基于 Electron、React 的监控应用。
- `TacAI-H2.1IPC/`：基于 PyQt5 的触觉传感器三维力可视化程序。
- `resources/`：项目资源文件。

## 开发

### TfgMonitor

```bash
cd TfgMonitor
npm install
npm start
```

### TacAI-H2.1IPC

安装 Python 依赖（包括 `PyQt5`）后运行：

```bash
cd TacAI-H2.1IPC
python main.py
```
